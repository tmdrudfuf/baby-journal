# Baby Journal

> Record in 10 seconds. Remember forever.

A private family memory system for parents and caregivers. Expo + React Native + Supabase + Cloudflare R2.

- Product & roadmap: [masterplan.md](masterplan.md)
- Current status: [docs/PROJECT_STATE.md](docs/PROJECT_STATE.md)
- Agent instructions: [AGENTS.md](AGENTS.md)

## Quick start

```
npm run bootstrap   # install deps, create .env from .env.example
npm start           # Expo dev server
npm run verify      # lint + typecheck + unit tests
npm run db:start    # local Supabase (requires Docker)
npm run db:test     # RLS/security tests
```
